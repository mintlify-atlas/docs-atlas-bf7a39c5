---
title: "Mapperly"
description: "A .NET source generator for object mappings — zero runtime reflection, readable output."
---

Mapperly generates object-to-object mapping code at compile time using .NET source generators. You define mapping method signatures; Mapperly writes the implementations. The result is fast, readable code with no runtime overhead.

## Why Mapperly?

<CardGroup cols={2}>
  <Card title="Zero runtime overhead" icon="bolt">
    All mapping code is generated at build time — no reflection, no dynamic code.
  </Card>
  <Card title="AOT & trimming safe" icon="shield-check">
    Fully compatible with NativeAOT and trimmed .NET applications.
  </Card>
  <Card title="Readable generated code" icon="eye">
    Output looks like hand-written code — easy to inspect and step through in a debugger.
  </Card>
  <Card title="Compile-time safety" icon="triangle-exclamation">
    Unmapped members produce build warnings or errors before your code ever runs.
  </Card>
</CardGroup>

## Quick start

<Steps>
  <Step title="Install the package">
    ```bash
    dotnet add package Riok.Mapperly
    ```
  </Step>
  <Step title="Declare a mapper">
    ```csharp
    using Riok.Mapperly.Abstractions;

    [Mapper]
    public partial class CarMapper
    {
        public partial CarDto CarToCarDto(Car car);
    }
    ```
  </Step>
  <Step title="Use it">
    ```csharp
    var mapper = new CarMapper();
    var dto = mapper.CarToCarDto(car);
    ```
  </Step>
</Steps>
